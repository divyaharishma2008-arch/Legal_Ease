# LegalEase: AI-Powered Legal Document Generator

Welcome to the **LegalEase** repository! This project leverages Generative AI (Google Gemini / Groq API) to automate the drafting of standard-compliant legal agreements such as NDAs, Rental Agreements, and Service Contracts in seconds.
